mend is a Node 22 command-line tool that applies file patches in four formats: unified diff, SEARCH/REPLACE, V4A, and JSON tool-call. It uses three tiers of whitespace-tolerant matching to locate target regions and applies changes atomically, so a run either applies every patch or none at all. It is intended for developers and automation that need controlled, scriptable edits to source trees.

## Run it

```sh
node main.ts [options] [PATCH]
```
